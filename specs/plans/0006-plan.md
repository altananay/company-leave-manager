## Risks & open questions

- **İmaj sürümleri:** 9.x'in hangi yaması sabitlenecek; `latest` yok. *Öneri: adım 1'de registry'den
  doğrula, üç imajı aynı yamaya sabitle.*
- **Windows + Docker soketi:** Filebeat konteyneri `/var/run/docker.sock` ile app konteynerinin
  loglarını okur; autodiscover koşulu `docker.container.name = leave-manager-app`. *Öneri: app'e
  sabit `container_name` ver; smoke ile doğrula; olmazsa dosya-tabanlı yedek (app log dosyası +
  mount) — ama önce soket.*
- **Filebeat özel ILM politikası:** 9.x'te `setup.ilm.policy_file` desteklenmezse, `filebeat-setup`
  yerine tek seferlik `es-init` (curl ile policy/template PUT) kullan. *Öneri: önce Filebeat setup;
  smoke'ta politika adı + 30d doğrulanır.*
- **Uygulama konteyneri:** jar adı `leave-manager-0.0.1-SNAPSHOT.jar`; `./target:/app:ro` + shell
  wildcard. *Öneri: `sh -c 'exec java -jar /app/leave-manager-*.jar'`; README'de `./mvnw package`
  önkoşulu.*
- **Bellek:** ES 512m + Kibana ~512m; stack ~2 GB. *Öneri: README'de yaz; profil isteğe bağlı.*
- **JSON konsol:** dev konsolu JSON olur (okunabilirlik düşer). *Öneri: kabul — sözleşme iki modda
  da JSON; README notu.*
- **Check sözleşmesi:** yeni `logging-config` adımı `check.conf`'u değiştirir → residue zorunlu.
  *Öneri: adım `[fast]` (konteynersiz, deterministik); `requires logging-config: docker compose version`.*
- **e2e/CI:** ELK başlatılmaz; mevcut suite değişmez. *Öneri: aynen.*
