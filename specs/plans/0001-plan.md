- **R-13 · Docker daemon kapalı — çözüldü.** Docker Desktop açıldı, `docker info` 28.5.1 döndürüyor;
  `test-integration` ve `e2e` bu makinede koşabilir.
- **doctor profil kararı:** `check.conf` şu an adım içermiyor, profil kararı yok (bootstrap
  durumu). Adımlar aktive edildikten sonra beklenen: Java 25 ✓, Node 24 ✓, Docker ✗ (kapalı) →
  `test-integration` ve `e2e` "not runnable". Karar: yukarıdaki R-13 ile Docker'ı açmak.
- **Actuator yanıt şekli:** `base-path=/api` + `show-details=never` tam `{"status":"UP"}` vermeli.
  Sapma olursa küçük bir `HealthController`'a düşülür (fallback).
- **Flyway 11:** PostgreSQL desteği ayrı artefakt (`flyway-database-postgresql`); unutulursa
  migration "unsupported database" ile kırmızı olur.
- **Playwright Chromium** ~150 MB indirir; BUILD'da bir kez `npx playwright install chromium`.
- **`npm ci` maliyeti:** her check koşusunda ~20–30 sn; `web-deps [fast]` adımı olarak kabul edildi.
- **TypeScript 7 / Vite 8 / ESLint uyumu:** araç zinciri sorun çıkarırsa TS 6.x'e düşülür (plan
  sapması değil, sürüm notu); spec'in sürüm pini etkilenmez.
- **Windows'ta `scripts/e2e`:** Git Bash ile POSIX olarak koşar; `trap` ile her yolda teardown.
